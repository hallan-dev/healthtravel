# Health Travel — Site Premium

Site web premium pour **Health Travel**, agence de tourisme médical (remplacement du site actuel healthtravel.fr, WordPress).

## Objectifs du projet

- Site **unique, enrichi et vendeur** pour une agence de tourisme médical
- Contenu **bien référencé (SEO)** — contrairement au site actuel qui est en `noindex`
- Design premium : palette de couleurs chic, dégradés pastels élégants
- Rubrique **témoignages** mise en avant
- Photos médicales adaptées à chaque acte / intervention
- Formulaire de **demande de devis** avec vidéo de présentation
- Sections dédiées par praticien (ex. Dr Hallan Khenissi) avec menus propres et liens de retour vers l'accueil

## Stack technique

- **React + TypeScript + Vite**
- **Tailwind CSS** + composants modernes
- Déploiement : prévisualisation Kimi + publication via GitHub

## Structure prévue

```
src/
  components/     # Composants réutilisables (hero, témoignages, devis...)
  pages/          # Accueil, Actes & Interventions, Témoignages, Praticiens, Devis
  assets/         # Photos médicales retouchées
```
